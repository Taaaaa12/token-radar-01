Token Radar ranks 226 pre-token protocols by implied value, using a value model built from the snapshot's own market data: category market-cap-to-TVL multiples, 7-day growth, launch-window age, and token-share. It ships a sortable, filterable dashboard with per-protocol model breakdowns, concrete farm plans, and a model sandbox that re-ranks the board live.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
